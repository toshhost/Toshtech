📂 PARTE 3 — MT MANAGER: Guia Completo

📦 O que é o MT Manager?

É um gerenciador de arquivos profissional para Android com dois painéis lado a lado, editor de código com sintaxe colorida, explorador de arquivos compactados, editor de APK e muito mais. Sem anúncios, leve e poderoso.

🗂️ 1 — Archive (Arquivos Compactados)

O que faz: Abre e edita arquivos .zip, .rar, .7z, .tar e até dentro de APK sem precisar extrair tudo primeiro — economiza tempo e espaço.

✅ Como usar:

  • Abrir: Toque no arquivo .zip / .apk → abre direto como uma pasta
  • Editar dentro: Toque em um arquivo dentro do zip → edita e salva sem extrair nada
  • Adicionar arquivos: Seleciona no outro painel → copia → cola direto dentro do zip aberto
  • Excluir: Toque longo → Excluir → salva automaticamente
  • Extrair tudo: Toque longo → Extrair → escolhe pasta de destino
  • Criar arquivo compactado: Seleciona arquivos → botão "Compactar" → escolhe formato (.zip, .7z, etc.)
💡 Dica única do MT: Diferente de todos os outros gerenciadores, o MT Manager não precisa descompactar para editar. Você altera um .js dentro de um .apk e ele salva direto — sem ocupar espaço extra! 🚀

🔍 2 — Explore (Explorador de Arquivos)

O que é: Navegação completa pelos arquivos do celular com dois painéis independentes lado a lado — a funcionalidade mais poderosa do app.

✅ Como usar:

┌──────────────────────────┐  ┌──────────────────────────┐
│     Painel Esquerdo      │  │     Painel Direito       │
│  /storage/emulated/0/    │  │  /home/tosh/projetos/    │
│  📁 ToshTech/            │  │  📁 backup/              │
│  📄 api_tosh.js          │  │  📄 api_tosh.js.bak      │
└──────────────────────────┘  └──────────────────────────┘
  • Navegar: Toque em pastas para entrar; toque em ".." para voltar
  • Copiar/Mover: Seleciona no painel esquerdo → cola no direito — arrasta entre painéis também funciona!
  • Selecionar: Toque longo em 1 arquivo → marca → toca nos outros para adicionar
  • Editar código: Toque no arquivo .js/.html/.css → Abrir com → Editor de Texto → sintaxe colorida automática!
  • Visualizar mídia: Toque direto em imagem/vídeo → abre em tela cheia com zoom e gestos
  • Propriedades: Toque longo → Propriedades → vê tamanho, permissões, data, caminho completo
  • Comparar pastas: Dois caminhos abertos → botão "Comparar" → vê arquivos diferentes de um lado e do outro

🛠️ 3 — Editor de APK

✅ Como usar:

  1. Localize o arquivo .apk no explorador
  2. Toque nele → escolha "Visualizar" ou "Editar"
  3. Navegue pelas pastas internas: res/ (recursos, ícones, textos), AndroidManifest.xml (configurações do app)
  4. Edite imagens, ícones, textos ou cores → clique em Salvar
  5. O MT recompila e assina o APK automaticamente
  6. Instale a nova versão
⚠️ Sempre faça uma cópia de segurança antes de editar! Se o APK não instalar mais, restaura o original.
🎯 Seu fluxo de trabalho perfeito:
1️⃣ MT Manager → edita arquivos .js/.html com sintaxe colorida
2️⃣ Salva → abre o Termux → executa node api_tosh.js
3️⃣ Tudo no celular — sem precisar de PC nenhum! 🚀

🌍 PARTE 4 — História e Origem das Linguagens

🐍 Python

→ 1991

👤 Criador: Guido van Rossum — Holanda

📖 A História: No final dos anos 80, Guido trabalhava no CWI. Insatisfeito com linguagens complicadas, criou algo simples e legível nas férias de Natal de 1989. A primeira versão saiu em fevereiro de 1991.

🎭 Nome: Vem de "Monty Python's Flying Circus" — programa de comédia britânico. Nada a ver com cobras!

📍 Onde está: IA, ciência de dados, automação, Google, YouTube, NASA, Netflix.

💻 Exemplo de Código:

def saudacao(nome):
    return f"Olá, {nome}! 🐍"

print(saudacao("Tosh"))

🟨 JavaScript

→ 1995

👤 Criador: Brendan Eich — em apenas 10 DIAS!

📖 A História: A Netscape precisava de uma linguagem para o navegador. Brendan criou tudo em 10 dias de trabalho intenso. De Mocha → LiveScript → JavaScript — nome só para aproveitar a fama do Java. Não tem nada a ver com Java!

🚀 Revolução: Em 2009, o Node.js nasceu — e o JS saiu do navegador para rodar no servidor. É a base da Tosh Tech!

📍 Onde está: Toda a web, servidores, apps, celular, robôs.

💻 Exemplo de Código:

function saudacao(nome) {
    return `Olá, ${nome}! 🟨`;
}
console.log(saudacao("Tosh"));

🐘 PHP

→ 1995

👤 Criador: Rasmus Lerdorf — Groenlândia/Canadá

📖 A História: Começou como scripts simples para rastrear visitas ao currículo dele. As pessoas pediam mais recursos e virou linguagem completa. Lançado em 1995.

🎭 Nome: De "Personal Home Page" → "PHP: Hypertext Preprocessor" — nome recursivo!

📍 Onde está: WordPress (43% da web!), lojas virtuais, blogs, fóruns, Laravel.

💻 Exemplo de Código:

📄 HTML

→ 1991

👤 Criador: Tim Berners-Lee — Reino Unido, no CERN

📖 A História: Os cientistas precisavam compartilhar documentos entre instituições. Tim criou o HTML + HTTP + URL em 1990. Liberou publicamente em 1991 — nasceu a World Wide Web.

⚠️ Importante: HTML NÃO é linguagem de programação — é de marcação. Não tem operadores lógicos nem matemáticos. Usa tags e atributos.

💻 Exemplo de Código:

<h1>Olá, Tosh! 📄</h1>
<p>Bem-vindo ao HTML — a base da web!</p>

🍃 MongoDB

→ 2009

👤 Criador: Equipe da 10gen — Nova York, EUA

📖 A História: Os bancos SQL eram rígidos e complexos. A 10gen criou algo flexível: dados como documentos JSON, sem tabelas fixas. Lançado em 2009.

🎭 Nome: Vem de "Humongous" — algo gigante. Projetado para volumes enormes de dados.

📍 Por que com Node.js: Armazena em formato BSON (JSON binário) — igual ao JavaScript. Você lê do banco e usa direto, sem converter nada!

💻 Exemplo de Código:

await db.collection("usuarios").insertOne({
    nome: "Tosh",
    cargo: "Dono"
});
